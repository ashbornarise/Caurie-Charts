{{ tr("Intelligence artificielle · Les agents") }}

{{ tr("L'IA rédige,") }} {{ tr("elle ne témoigne jamais") }}

{{ tr("Le choix fondateur tient en une phrase : un modèle de langage n'est jamais une source. Il reformule, résume, titre et classe des faits qu'on lui fournit, mais il n'a pas le droit d'en ajouter. Toute l'architecture des agents découle de ce principe.") }}

{{ tr("Ce principe vient d'un test. On a demandé à une IA, sans accès au web, les records de l'album d'un rappeur français. Elle a répondu avec assurance, avec des chiffres précis et faux. Depuis, aucun agent ne travaille « de mémoire ». Chaque agent reçoit un dossier fermé (les articles, les relevés, les chiffres calculés) et doit répondre dans un format JSON strict, champ par champ. Une réponse hors format est rejetée ; une affirmation absente du dossier est supprimée par le relecteur.") }}

{{ tr("Les agents utilisent les offres gratuites de plusieurs fournisseurs, avec une chaîne de secours : Gemini d'abord, puis Groq, puis OpenRouter. Les demandes sont groupées par lots de dix sujets pour économiser les quotas. Quand tous les quotas sont épuisés, la machine ne publie pas un texte bâclé : elle reporte l'étape au rattrapage.") }}
