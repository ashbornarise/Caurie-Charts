Où sont stockées les données

Les données sont stockées dans l'Union européenne : base de données à Francfort (Allemagne), fichiers envoyés à Paris (France), chez les prestataires indiqués ci-dessus et dans les mentions légales.

Vercel et GitHub sont des sociétés établies aux États-Unis et peuvent accéder aux données pour assurer leur service. Ces transferts hors de l'Union européenne sont encadrés par les garanties prévues dans leurs accords de traitement des données (clauses contractuelles types de la Commission européenne).

Vos droits

Vous pouvez demander l'accès à vos données, leur rectification, leur effacement, la limitation du traitement, leur portabilité, ou vous opposer au traitement fondé sur l'intérêt légitime. Un artiste peut demander la correction de sa fiche. Écrivez à {{ legal('privacy_email') }} ou via le formulaire de contact ; nous répondons sous un mois.

Vous pouvez aussi saisir l'autorité de protection des données de votre pays, par exemple :

  • Togo : Instance de protection des données à caractère personnel (IPDCP), loi n° 2019-014 du 29 octobre 2019 ;
  • France et Union européenne : CNIL, règlement général sur la protection des données (RGPD) ;
  • Bénin : Autorité de protection des données à caractère personnel (APDP), Code du numérique ;
  • Côte d'Ivoire : ARTCI, loi n° 2013-450 ;
  • Sénégal : Commission des données personnelles (CDP), loi n° 2008-12 ;
  • Ghana : Data Protection Commission, Data Protection Act 2012 (Act 843).
