{{ tr("Notre mission") }}

{{ tr("La musique d’Afrique de l’Ouest est parmi les plus écoutées du continent, mais personne ne la mesurait de façon régulière, pays par pays, avec une méthode ouverte. {{ tr("La méthode en bref") }}

  • {{ tr("Une formule publique et datée : chaque changement porte un numéro de version et une date d’effet, et les classements déjà publiés ne sont jamais recalculés.") }}
  • {{ tr("Un équilibre entre vidéo et écoute : YouTube compte pour moitié, les plateformes d’écoute pour l’autre moitié.") }}
  • {{ tr("Des règles pour la lisibilité : trois titres au plus par artiste dans un Top, et deux sources au moins pour entrer dans le Top 5.") }}
  • {{ tr("Des alertes pour vérification : une progression soudaine ou un chiffre inhabituel fait examiner le titre avant publication ; une alerte n’est pas une sanction.") }}
  • {{ tr("Un indice de fiabilité sur 100, affiché sur chaque classement : il dit sur combien de données repose le classement du pays.") }}

{{ tr("Déclarer ses chiffres") }}

{{ tr("Certaines plateformes ne publient pas leurs chiffres. Artistes et labels peuvent les déclarer. Les critères :") }}

  1. {{ tr("une capture de l’espace artiste (Spotify for Artists, Audiomack, Boomplay…) qui montre la période et le nombre d’écoutes ;") }}
  2. {{ tr("une période déjà terminée, de trois mois au plus, et les mêmes chiffres dans le formulaire ;") }}
  3. {{ tr("une vérification par notre équipe avant tout calcul ; une déclaration n’est comptée que si une donnée publique la recoupe, et elle est écartée si elle s’en écarte de plus de 30 % ;") }}
